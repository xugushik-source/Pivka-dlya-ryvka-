# Голосовой продавец — что сделать владельцу

Весь код готов и лежит в ветке `feature/voice-seller-trilingual`. Серверная функция `voice-session` уже
развёрнута в Supabase. Боевой сайт (`main`, pivkadlaryvka.ge) **не изменён**.

## Единственное действие: ключ OpenAI

1. Откройте https://platform.openai.com/api-keys → **Create new secret key** → скопируйте ключ (`sk-…`).
   На счёте OpenAI должен быть баланс (Billing).
2. Откройте https://supabase.com/dashboard/project/uphnuzgaildmjrttmbaq/functions/secrets
3. **Add new secret**: Name — `OPENAI_API_KEY`, Value — ваш ключ → **Save**.

Ключ хранится только в Supabase. В коде, на сайте и в GitHub его нет и не будет.

Пока ключа нет (или исчерпан дневной лимит), кнопки «Скажи, что хочешь» на сайте **просто нет** — покупатели
не видят недоделанную функцию. Кнопка появляется сама, когда сервер подтверждает, что голос работает.
Посмотреть окно без ключа (только текстовый режим): добавьте к адресу `?voice=1`.

После этого голосовой продавец сразу работает в предварительном просмотре ветки:
https://raw.githack.com/xugushik-source/Pivka-dlya-ryvka-/feature/voice-seller-trilingual/index.html

## Необязательные настройки (там же, в Secrets)

| Имя | По умолчанию | Что значит |
|---|---|---|
| `VOICE_MODEL` | `gpt-realtime-2.1` | Модель. Дешевле: `gpt-realtime-2.1-mini` |
| `VOICE_VOICE` | `marin` | Голос продавца (`cedar`, `marin`, `alloy`, …) |
| `VOICE_DAILY_LIMIT` | `300` | Сколько разговоров в сутки на весь магазин |
| `VOICE_PER_HOUR` | `8` | Сколько разговоров в час с одного устройства/сети |
| `VOICE_MIN_GAP_SECONDS` | `20` | Минимальная пауза между новыми разговорами |
| `VOICE_MAX_SECONDS` | `600` | Максимальная длина одного разговора (сек) |

Когда лимит исчерпан или ключа нет, кнопка всё равно открывает окно: простые запросы понимаются по тексту
(«нас шестеро, бюджет 150», «убери рыбу», «сколько до подарка»), а обычный магазин работает как всегда.

## Как выпустить на боевой сайт (после проверки)

Ничего настраивать не нужно: одобрите слияние ветки в `main` (PR). Боевой домен pivkadlaryvka.ge уже в списке
разрешённых для функции `voice-session`.

## Для разработчика: как это устроено

**Файлы**
- `supabase/functions/voice-session/index.ts` — выдаёт одноразовый ключ OpenAI Realtime (`ek_…`, живёт 60 с),
  инструкции продавца и описание инструментов; проверяет домен, лимиты (по `store_events`), пишет
  `voice_secret_issued` / `voice_error`. Модель, голос, лимиты — в одном объекте `CONFIG`.
- `js/voice-agent.js` — WebRTC с OpenAI (`/v1/realtime/calls`, канал `oai-events`): микрофон, голос продавца,
  вызовы инструментов, перебивание, тайм-ауты (90 с тишины, максимум сессии, 30 с в фоне), закрытие.
- `js/voice-tools.js` — инструменты поверх существующего `store.js` (корзина, каталог, рывки, подарки, доставка,
  PASS, оформление). Проверяют id и количества, цены берут только из каталога.
- `js/recommendation-engine.js` — детерминированный подбор корзины (люди, бюджет, что пьют, исключения).
- `js/voice-local.js` — понимание простых фраз RU/KA/HY без ИИ (запасной режим текстового поля).
- `js/voice-ui.js` — кнопка «Скажи, что хочешь» и окно продавца (RU/KA/HY).

**Правила, которые держит код, а не модель**
- товар — только существующий `product_id` из каталога; рывок — только существующий `bundle_id`;
- цена/сумма — только из каталога и `orderBase()` (ночные цены, подарки, доставка — существующая логика);
- разливное: минимум и шаг из товара (2 л);
- заказ не отправляется: `prepare_checkout` открывает обычную форму, где клиент сам подтверждает 18+ и заказ;
- сервер заказа (`create_store_order`) по-прежнему пересчитывает всё сам.

**Аналитика (без аудио и без текста разговора):** `voice_open`, `voice_session_started`, `voice_language`,
`voice_request` (язык, длина), `voice_recommendation`, `voice_recommendation_accepted`, `voice_add_to_cart`,
`voice_remove_from_cart`, `voice_checkout_open`, `voice_error`, `voice_session_end`.
